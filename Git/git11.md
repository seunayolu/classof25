# This is a Git Readme file

Git is a version control system. To download, kindly check the [Official Website](https://git-scm.com/)

## How to Use Git

```sh
mkdir gitrepo
cd gitrepo
git init --initial-branch=dev
```
### Git Clone Command

`git clone`

To clone a repo use the command below

```sh
git clone https://github.com/seunayolu/classof25.git
```
